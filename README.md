こんだてーる

このアプリではご飯のメニューを決めるのが面倒なとき自分で設定した一覧からランダムに料理を決定することができます。

**公開URL：** https://kondate-ru.vercel.app/



[アプリの画面](screenshot.png)



一人暮らしで自炊をする人のためのアプリ

なにをつくるか決めるのが面倒な問題を解決

使い方

1. 料理名の欄に追加したい料理の選択肢を入力して追加、献立を決めるボタンでその中からランダムピックアップ　　します。
2. 料理にはタグをつけることができ、タグごとに絞り込んでランダムピックアップができます。
3. 追加した料理またはタグの削除・編集することができます。


## 主な機能

| 機能 | 説明 |
|---|---|
| 料理の登録、削除| 料理を登録し、削除します|
| ランダムピックアップ |登録された料理からランダムに一つピックアップします|
| タグ機能| 料理にはタグを付けることができ、つけられたタグごとに絞り込んでランダムピックアップします|

## 今回は作らなかった機能

- 冷蔵庫の中身から作れる料理を表示
- 料理のレシピを表示

## ローカルで動かす方法

このアプリは HTML / CSS / JavaScript だけでできています。
特別な準備は必要ありません。

1. このリポジトリをダウンロード（または `git clone`）します。
2. `index.html` をブラウザで開きます。

> VS Code で開いている場合は、Live Server 拡張を使うと確認が楽です。
- データはブラウザに保存されます。**別のブラウザや別の端末では引き継がれません。**
- ブラウザの履歴やサイトデータを削除すると、データも消えます。
